# Recenzie Ciocolată 🍫

Aceasta este o aplicație web simplă realizată cu HTML, CSS și JavaScript care permite utilizatorului să evalueze o ciocolată oferind un număr de stele între 1 și 5.

## Funcționalități:
- Afișează o imagine reprezentativă
- Permite introducerea unui număr de stele
- Afișează stelele pe ecran în timp real
- Afișează un mesaj de confirmare
- Stilizare modernă cu CSS

🔗 [Vezi aplicația live](https://bodeac00.github.io/recenzie-ciocolata/)
